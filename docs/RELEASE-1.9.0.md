# 1.9.0 发布与验证

本版本把已使用的系统地区设置、Clash Verge 分流与 DNS、浏览器专用代理入口和 AdsPower 代理配置集中到 macOS App 的“环境配置”。订阅缺少安装时的代理组时可自动补建，初始使用 REJECT，等待用户选择节点。网络配置只保留一层修改前备份，失败时回退，外部改动不覆盖。

AdsPower 配置只操作明确选择且确认已关闭的环境。API 密钥仅通过标准输入传递，不保存；WebRTC 缺少可读回的原值时显示手动步骤。普通浏览器的 GPU、字体、UA 不做伪装修改。监控在没有 Claude 桌面进程时保持安静，仅对影响实际进程的事件通知。

## 交付内容

- Apple Silicon / Intel 通用完整 App ZIP 与 DMG：主程序、通知助手、完整安装资源。
- 完整源码 ZIP 与 installer-kit ZIP。
- 源码组件清单与发布工件 SHA256。
- GitHub 根目录构建、校验和发布工作流；源码位于 `claude-switcher/`。

预编译安装需要 Python 3，不要求 Swift 编译器；从源码构建需要 Xcode 工具。App 使用 ad-hoc 签名，未做 Apple Developer ID 公证。

## 验证证据

- Python 隔离回归覆盖浏览器配置、事务回退、外部变更冲突、组件更新固定提交、完整 App 安装验证、规则与监控状态机。本次完整测试共 118 项通过，其中持续监控 40 项；通知助手的原生自测也通过。
- 主程序与通知助手已在 macOS 完成 `arm64`、`x86_64` 构建、签名和包结构验证。
- 四份已有订阅在临时目录离线应用新配置后，均通过本机 Mihomo 配置校验；其中三份需要自动补建代理组。见 [脱敏配置校验证据](environment-native-evidence.json)。没有为此切换真实订阅。
- 三页界面经过实际渲染检查；界面动作使用隔离假核心验证 JSON 输入、失败和部分完成显示、预览失效及密钥处理。
- AdsPower API 配置/恢复测试使用本机假 API。此前人工配置的实际 AdsPower 专用入口已有路由证据，但这不能代替新 Local API 功能在每种版本/套餐上的联调。

以上不是 Windows/Linux 真机验收，也不包含 Claude 登录、真实账号切换或浏览器完整 ICE/DNS 泄漏审计。配置保存、fake-IP 返回、单个探测成功均不等同“零泄漏”。
