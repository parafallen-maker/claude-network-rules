# 账号事务与中断恢复（macOS / Linux）

账号数据仍使用 `~/.claude-switcher/accounts/A` 至 `D`，当前账号仍记录在 `current`。升级不会改写既有快照的内容，也不会将不明归属的临时目录当作垃圾删除。

## 正常切换

核心脚本与 `account_state.py` 共用 `~/.claude-switcher/state.lock`。切换、导入、导出和组件更新必须持有同一个锁；另一个操作正在执行时返回忙碌状态，不同时修改账号资料。`fix`、`set-region`、`set-client`、`write-merge-rules` 和 `set-check-config` 等配置写入口也使用该锁，避免更新期间覆盖核心或网络配置。不要手动删除锁文件：锁由操作系统维护，删除文件反而会破坏互斥。

切换先准备独立的新运行目录和原账号快照，再写入 `account-transaction.json`，随后交换目录、原子提交 `current`，最后清理本次事务的旧副本。提交之前始终保留原运行目录和原快照。macOS 优先使用 APFS clonefile，Linux 优先使用 reflink；不支持时回退完整复制，空间不足时停止并保留原数据。

`keep-in-workspace.txt` 中的通用设置在新目录准备阶段合并，失败时不会改变当前运行目录。越界路径和源符号链接不参与复制；目标路径含符号链接时拒绝切换，避免写入账号目录之外。

## 程序退出、超时或断电后

运行以下命令可只恢复数据，不启动 Claude：

```bash
# macOS
~/.local/bin/claude-switch.sh recover

# Linux
~/.local/bin/claude-switch recover
```

恢复命令先确认对应应用已退出，再持锁处理日志。下次正常切换也会先处理未完成事务。未提交事务回滚到原账号；已提交事务完成剩余清理。回滚时可能产生的额外数据保留在 `transactions/<事务ID>/` 和运行目录旁的 `.claude-switcher-<事务ID>.*`，不会静默删除。这些目录可能包含敏感的登录资料，应按账号备份保护。

`status` 在存在可识别事务时附带 `pending=1`。这是待恢复提示，不表示上次切换成功。当前账号标记或事务记录损坏、原始副本缺失时会停止，不能通过猜测账号归属继续。

如果同时存在未完成的安装或组件更新，`status` 会附带 `blocked=install` 或 `blocked=update`。所有账号写操作（包括账号恢复）、快照导出和公开配置写入口都会停止；必须先通过对应安装器或更新器完成恢复，不能把混合组件状态当作启动许可。账号事务本身待恢复时仍可修改检查设置或修复网络，配置修复不依赖账号目录是否可用。

GUI 操作超时会终止该操作的进程组，并在子进程退出前保持互斥锁。不要因为界面显示超时就手动移除锁或删除恢复目录。

## 从旧版本遗留的恢复文件升级

如果发现旧版本产生的 `accounts/A.new`、`A.previous`、`A.tmp`（B–D 同理）、运行目录旁的 `.new/.old` 或 `keep-stage`，程序会保留并停止。旧版本没有足够的事务记录，无法自动证明哪份数据属于哪个账号。

先退出 Claude / 对应浏览器，完整备份整个 `~/.claude-switcher` 和运行数据目录，再核对恢复副本的账号归属。不要直接删除这些目录，也不要通过导入覆盖它们。确认并恢复后，可将剩余副本移到独立备份目录，再重试切换。

## 快照导入、导出

导入使用独立随机暂存目录，仅清理本次创建的暂存文件。已有目标快照、正在使用的槽位、未完成事务和旧版恢复资料都会阻止导入。镜像中的账号、格式和版本必须匹配；符号链接和特殊文件被拒绝。镜像挂载失败或元数据无效不会删除旧恢复副本。

导出只允许已归档且非当前使用的账号。密码通过标准输入提供；导出镜像校验完成后才写入目标文件，已有文件不会被覆盖。macOS 镜像挂载、APFS 行为和真实 Claude 登录态仍需在 macOS 真机完成验收。

## Linux 浏览器范围

为兼容旧安装，默认运行目录仍为原有 Chrome / Chromium 配置目录。只会主动请求退出命令行明确指定 `--user-data-dir=<该目录>` 的浏览器，并等待其已识别的辅助进程退出。

普通浏览器使用默认配置、命令行没有明确的目录参数时，切换器会要求用户手动完全退出，不会强制关闭普通浏览器。其他明确指定不同配置目录的浏览器保持运行。原浏览器或其辅助进程未退出、配置仍有活动锁时，账号资料不会被切换。

这些保证针对本机文件操作的一致性。数据目录快照不等同于硬件、系统用户或服务端身份隔离。
